# Unisphere_exporter

Unisphere Exporter connects to the Unity console, scrape metric and logs.
and send them to Backends like Prometheus, Loki...

## Collector
| Collector       | Default Enabled  | Type     | Description                                                                               |
|-----------------|------------------|----------|-------------------------------------------------------------------------------------------|
| alert           | false            | `log`    | Information about alerts generated by the storage system. (collect alert from 1hour ago)  |
| basicSystemInfo | true             | `metric` | Information about storage system's basic information.                                     |
| capacity        | true             | `metric` | Information about capacity on storage system.                                             |
| disk            | false            | `metric` | Information about disk configuration on a storage system.                                 |
| ethernetPort    | false            | `metric` | Information about ethernet port configuration on a storage system.                        |
| event           | false            | `log`    | Information about events generated by the storage system. (collect event from 1 hour ago) |
| fcPort          | false            | `metric` | Information about fibre channel port configuration on a storage system.                   |
| healthCheck     | true(CANNOT FIX) | `metric` | for connection check                                                                      |
| host            | false            | `metric` | Information about host configuration on a storage system.                                 |
| lun             | true             | `metric` | Information about lun configuration on a storage system.                                  |
| metric          | false            | `metric` | collect storage's performances using realtimequery.                                       |
